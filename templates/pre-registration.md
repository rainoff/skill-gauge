# Pre-registration 模板 — 開跑前先寫定

> 本檔在**開跑之前**寫完並 commit。跑完不得回頭改判準；要改，開新版本、留下這一版。
> 防的是最常見的自欺：先看結果，再挑會讓結果好看的判準。

## 條件宣告（必填——結論只在這四個條件內成立）

| 條件 | 本次量測的值 |
|------|-------------|
| 模型 | {受測執行用哪個模型？評分用哪個模型？兩者都要填實際跑的值，不填「預計」} |
| harness | {量測環境裡還有什麼：全域規則？記憶？其他 skill？隔離做法寫具體（見下方執行紀律）} |
| 任務分佈 | {題目覆蓋哪些任務型態？沒覆蓋的型態，結論原理上不外推} |
| 使用者既有能力 | {prompt 裡自帶了多少紀律？使用者（或題目）既有的習慣等同一層看不見的 harness——對照臂拿到的紀律句要逐字列出} |

## 受測物

- skill：{名稱＋版本快照（commit hash 或日期）——模型與 skill 都會更新，凍結不了就記錄}
- 類型（必填，決定後面判斷標準怎麼設計）：{**產出物型**（產出是檔案或頁面——判斷標準可機械化，四族斷言直接用）／**方法注入型**（改變 AI 做事的方式，效果散在過程——量測標準用它自己的官方宣稱，逐字引用；「使用方式照官方說明設置」進前置檢查並逐字記錄）／**互動型**（產出是一場與使用者的對話——評分靠 AI 判對話品質、主觀性最重；效果跟著使用者本來的能力變，「在誰身上量的」最敏感）／其他（描述它的產出長什麼樣，再決定判斷標準的形態）}
- 預期哪裡來：{預設＝受測 skill 自己的 description 與宣稱，**逐字引用**——量「它宣稱的效果在你的條件下有沒有出現」。這是最不武斷的標準：規格是 skill 作者自己給的，沒人能指控出題偏頗。注意但書：這回答不了「你的工作流裡值不值得用它」——你的日常可能根本碰不到它宣稱的場景；要量那個，題目改從你的真實使用場景出，並在報告寫明兩者的差別}
- 兩臂定義：
  - with_skill 臂拿到：{逐項列——skill 全文？skill 連帶載入的其他東西？}
  - 對照臂拿到：{逐項列。**誠實檢查：對照臂是不是真的「無 skill」？** 若 prompt 含 skill 的核心紀律句、或材料本身是 skill 某一步的產物，你量到的是殘餘差值不是完整效果——現在就寫下來，不要等跑完才發現}

## 四族斷言

| 族 | 進不進評分 | 本次內容 |
|----|-----------|---------|
| 前置檢查（gate） | ❌ 不進分。任一不過＝該 run 無效，記 invalid、補跑 | {格式、語言、自包含等「模板照抄就會過」的項目全部歸此——它們進評分＝拿考卷作答} |
| 事實紀律 | ✅ 逐項二元，附證據位置 | {不捏造識別碼／日期／出處、不把推測寫成事實…} |
| 判斷紀律 | ✅ 逐項二元 | {不代替裁決者下結論、不擅自標記推薦…} |
| 取向觀察 | ❌ 不進分，強制記錄 | {二元判準抓不到的風格與取向差異；原始輸出一律留存} |

## 規模

{題數} × 2 配置 × {每配置 run 數} ＝ {總 run 數}。
小規模下，加重複次數通常比加題目划算；設了幾就跑滿幾——設 3 跑 1 的數據不要用。

## 能說／不能說（先寫死）

- **能說**：{描述性、僅限本次 run 的話}
- **不能說**：{因果通則／外推到題組外任務／跨模型比較／…——現在寫，跑完照著念}

## 執行紀律

1. fresh session、乾淨 workspace，每 run 隔離。
2. 隔離操作化（採 skill-forge cli-executor 做法，並依 2026-08-17 兩機已知答案探針補正；可直接照抄的指令見 README「怎麼跑一次量測」）：在**不位於 home 底下**的暫存目錄建隔離環境（cwd 及其每一層祖先目錄都不得有 `.claude/`——`project` 來源會把祖先目錄的 `.claude/rules/*.md` 一併當 project rules 載入；mac 的 `$TMPDIR` 在 `/var/folders/…` 可用，Windows 的 `%TEMP%` 在使用者目錄底下**不可用**），受測 skill 以 project 層放入該目錄的 `.claude/skills/`；執行時同時給三件：`--setting-sources project`、`--strict-mcp-config`、環境變數 `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`（前兩支旗標管不到自動記憶，這是官方記載的行為，不加它記憶照樣載入）。兩臂旗標與環境變數對稱。**用前先做已知答案檢查，且每格兩臂**：同一個目錄、同一句問句，只差有無上述旗標——不帶旗標那臂要讀得到一個指定的全域規則條款／記憶索引／全域 skill，帶旗標那臂要讀不到；只有「讀不到」沒有「同目錄讀得到」的對照，不能歸因給旗標（可能只是換了目錄）。目前已驗的 canary：一條 user rule、一個 user skill、一個 user hook、auto-memory 索引；MCP 未設 canary，不在已驗範圍。
3. 對照臂的誠實檢查：確認對照臂不只「沒用 skill」，而是「skill 不在可用清單上」——skill 在清單上但沒被用，量到的是上界不是乾淨差值。
4. gate 不過的 run 記 invalid 補跑（逐字相同 prompt），不算失敗也不算通過。
5. 評分模型欄位**實填**，不留佔位符。
6. 跑完先填 results（數據），才可寫任何結論；結論措辭受「能說／不能說」約束。
