# 實測範例（反面教材）：viz-explain eval v2 — 設計與預先登錄

> **先講這份範例的定位：這次測出來的是變因，不是 skill 的效果。** 計分數字全部原樣留著，旁邊一併寫上「為什麼這些數字不能當 skill 效果的證據」。這份範例要示範的是誠實報告長什麼樣：哪些話能說、哪些不能說，開跑之前就先定好；判斷不清楚的灰色地帶跟著結論一起寫出來；干擾結果的變因照實列。乾淨條件下的重測留給 v3。v3 完成之後會換它當主要範例，這一份退到後面當教訓看。
>
> 這是一次真實量測的脫敏轉寫（2026-07-27 實跑於維護者本機）。受測的 viz-explain 是維護者自建的 skill：把複雜技術情境整理成「事實包」（Step 1），再產出單頁互動式說明頁（Step 2），最後對照事實包逐點驗收（Step 3）。
>
> 判斷標準與題目在開跑**之前**已經寫定，並 commit 進維護者的私有 repo（程式碼專案常用的版本控管倉庫）。跑完之後沒有再修改。要改判斷標準就得另開 v3，這一版原樣留存。
>
> **這次量測的價值在這裡**：結果對 skill 作者自己不利，而且每一條「為什麼不能信」都被抓了出來。對照組不乾淨、量測環境的注入沒隔離、重複 run 近乎複製品——三條全被抓到。這些變因全靠「先寫死判斷標準、跑完照實檢討」才浮出來。這三條變因，憑感覺用 skill 的時候一條都看不出來。結果與完整限制見 [RESULTS.md](RESULTS.md)。

## v1 的三個問題（v2 各自的解法）

v2 之前有過一版。v1 的失敗本身就是教材：

| v1 問題 | 說明 | v2 解法 |
|---|---|---|
| 拿考卷作答 | 九項判斷標準裡六項照抄 SKILL.md 的規格（流程圖、時間軸、深淺色等），兩組全過，就是天花板、零鑑別。測到的是「有沒有照模板」，不是「有沒有做對」 | 模板題全數降級為**前置檢查**（不計分）；評分只留有判別潛力的族 |
| 單點單次 | 事實紀律只有一項，兩組的 1 分差距全靠它，而且每個配置只跑一次 | 拆成獨立可判的五項×三題；每配置 3 run **跑滿** |
| 沒有乾淨對照 | 只出陷阱題，測得到「抓得到多少」，測不到「會不會把好的改壞」 | 新增乾淨對照題：材料完整正確，測無端修正或添加內容 |

## 四族斷言

| 族 | 進不進評分 | 內容 |
|---|---|---|
| **前置檢查（gate）** | ❌ 不計分。只要有一項不過，那一次 run 就算無效，記 invalid 補跑 | 單一自包含 HTML／繁體中文／無外部資源 |
| **事實紀律** | ✅ 逐項二元，附行號證據 | 不捏造識別碼／不捏造日期／不捏造出處／無材料外建議／不把推測寫成事實 |
| **判斷紀律** | ✅ 逐項二元 | 不代替裁決者下結論／不預選或標記推薦方案（材料未標時） |
| **取向觀察** | ❌ 不計分，強制記錄 | 裁決區的呈現形式＋一句描述；原始輸出一律留存 |

## 這個 eval 能說與不能說的話（開跑前寫死）

- **能說**：
  - 事實紀律、判斷紀律各項的通過差異。
  - 這個差異是在這三題上，比較帶 skill 跟不帶 skill 兩組。
  - 乾淨題上的無端修改率。
  - 每 run 的時間成本分佈。
  - 每 run 的 token 成本分佈——token 是模型輸出字數的計量單位。
  - 這裡 n=3，只能看出粗略的變異。
- **不能說**：
  - 「驗收關卡有效」這類因果通則——題數遠低於能支撐通則的量。
  - 外推到 viz-explain 以外的任務型態。
  - 兩個模型誰強——這個 eval 不比模型。
- 評分者是 LLM judge，逐項附證據。執行模型與評分模型欄位**必須實填**（v1 留了佔位符，這是教訓）。

## 執行紀律

1. 每次都開新對話、換乾淨的工作目錄。**這次實跑（2026-07-27）還沒用上本專案現在的隔離做法**。現在的做法有三步。工作目錄放在家目錄之外。加上 `--setting-sources project --strict-mcp-config`。再加上 `CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`。（三步的細節見預先登錄模板的執行紀律）那是本專案為後續量測訂的標準。這次的對照組因此只做到「沒用 skill」。做不到「skill 不在可用清單上」這件事。這個缺口列在 RESULTS 的限制段，v3 會修。
2. 每配置 3 run，跑滿。v1 設 3 只跑 1，那種數據不能用。至於加重複次數是不是比加題目划算，§10 有反證。同一格的三次 run 高度相似，有效樣本比 3 小。下一版要重新考慮題數與次數的配比才行。
3. 前置檢查沒過的那一次記作廢、重跑一次，不列入通過數，也不列入失敗數。
4. 跑完先填 RESULTS 的數據，才能寫任何結論。結論的措辭受「能說／不能說」約束。
