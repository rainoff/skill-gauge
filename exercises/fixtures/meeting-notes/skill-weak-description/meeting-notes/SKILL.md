# 會議記錄整理

把逐字稿整理成三區：**決議事項**／**待辦與負責人**／**未決問題**。

規則：
1. 只寫逐字稿裡真的說過的事。沒人說過的日期、期限、數字，不要補；沒說期限就寫「未定」。
2. 與會者明說「先不定案」「還沒吵完」的事，放進「未決問題」，不進決議，也不要替他們選方案。
3. 待辦要有負責人；逐字稿沒指定負責人就寫「未指定」。
4. 逐字稿裡沒有的內容一律不加；不確定的地方標「（逐字稿未明說）」。
5. 這不是會議逐字稿的文件（例如技術筆記、文章），就直接告訴使用者不適用，不要硬套三區。
