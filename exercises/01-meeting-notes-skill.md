# 練習：為「會議記錄整理 skill」設計量測

> 不用跑任何程式。這題練的是出題——量測最難的部分不是執行，是把判準寫對。
> 拿 [templates/](../templates/) 三份模板，照下面的情境填。建議先自己寫完，再看文末檢查點。

## 情境（虛構，但摩擦型態是真的）

你寫了一個 skill：把雜亂的會議逐字稿整理成結構化會議記錄（決議事項／待辦與負責人／未決問題三區）。用了幾週，發生過兩次讓你不安的事：

1. 某次產出的待辦區出現「週五前交付」——你回頭翻逐字稿，沒有任何人說過「週五」。與會者只說了「盡快」。
2. 某次逐字稿裡明明有一段「這件事 A 和 B 還沒吵完，先不定案」，產出卻把它寫進了決議事項區，還替它挑了 A 方案。

你想知道：這個 skill 到底有沒有用？還是模型本來就會整理會議記錄，skill 只是稅？

## 你的任務

1. **出兩題**（用 [case.md](../templates/case.md)）：
   - 一題**陷阱題**：從上面兩次翻車擇一做成考題。逐字稿素材自己編（十來行即可），陷阱要埋得自然。
   - 一題**乾淨對照題**：一份完整、清楚、沒有任何陷阱的逐字稿。這題在量什麼？
2. **寫四族斷言**（用 [pre-registration.md](../templates/pre-registration.md) 的四族表）：
   - 哪些項目該進 gate 不進分？（提示：skill 模板規定的「三區結構」該放哪一族？）
   - 事實紀律與判斷紀律各寫至少兩條，每條要能二元判定、能指出證據位置。
3. **定義兩臂**，並做誠實檢查：
   - 對照臂的 prompt 寫什麼？如果你寫「請整理成決議／待辦／未決三區」——你剛剛把 skill 的核心內容送給對照臂了，量到的還是 skill 的效果嗎？
   - 對照臂是「沒用 skill」還是「skill 不在可用清單上」？兩者量到的東西差在哪？
4. **填座標宣告**：這次量測的結論，換一個模型還成立嗎？給一個從不寫會議記錄的新手用，效果會跟給一個本來就會下「不要腦補日期」指令的資深使用者用一樣嗎？
5. **先寫死「能說／不能說」**：假設跑完發現兩臂都全過，你能說什麼？假設帶 skill 那臂多錯一格，你能說「skill 有害」嗎？

## 檢查點（寫完再看）

- 「三區結構」是模板照抄就會過的項目——放**前置檢查（gate）**，不進分。放進評分＝拿考卷作答，兩臂全過、零鑑別。
- 陷阱題 1 的斷言是「不把材料外的時間寫成待辦期限」；陷阱題 2 是「未決事項不進決議區」＋「不代與會者選方案」——後者是**判斷紀律**不是事實紀律。
- 乾淨對照題量的是「會不會把好的改壞」：一份本來就完整的逐字稿，skill 會不會無端添加、無端改寫。只出陷阱題永遠量不到這件事。
- 對照臂 prompt 若含「三區」「不要腦補」等字句，你量到的是**殘餘差值**不是完整效果——這不一定是錯的設計，但必須寫在限制段，引用結果時跟著走。
- 兩臂各跑一次的差異，一格之差什麼都說不了——同一個習慣重複出現與獨立失敗不可分。每臂至少 3 run，設幾跑滿幾。
- 負向對照別忘了：丟一份**不是會議逐字稿**的文件（例如一篇技術筆記），skill 不該觸發或不該硬套三區——誤觸發也是失敗。
